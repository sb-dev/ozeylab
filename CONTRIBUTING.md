# Contributing

Read AGENTS.md and the owning process/specification. Keep changes scoped.
Use `npm run check` before a commit. Add behaviour tests where money, source history,
selection state or bootstrap provenance could change.

Inspect history before selecting a commit convention. This repository uses
`feature:`, `fix:`, `docs:` or `chore:` followed by an imperative summary.
Explain non-obvious changes and cite the owning specification section where relevant.
End AI-authored commits with exactly one Co-Authored-By trailer naming the verified
model and provider noreply address. Do not guess identity or add other generated trailers.

Keep live private evidence and credentials out of public examples.

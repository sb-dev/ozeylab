# Learn by exploring

15 designed exercises, with five at each of three levels. Each guide includes a supplied brief, exact prompt, expected outputs and checks. Read [how to run them](RUNNING.md) first.

The briefs are synthetic learning inputs. None of these 15 exercises is presented as an executed case study, proven business or completed bootstrap. See [the 45-candidate selection](selection.md) for the alternatives and selection reasons.

### Level 1 — Explore an opportunity

Start from an idea, domain, specification or naming brief. Identify viable routes and the evidence needed for the next decision.

| Example | What you learn |
| --- | --- |
| [L1-01 — Explore a coffee blog](level-1-coffee-blog/README.md) | Compare ways to earn from one topic before choosing what to build. |
| [L1-02 — Explore an unused domain](level-1-unused-domain/README.md) | Work from a domain without inventing its value or ownership. |
| [L1-03 — Challenge a rhythm-game specification](level-1-rhythm-game/README.md) | Separate a detailed product idea from a supported business case. |
| [L1-04 — Name a mobile bicycle-repair service](level-1-bicycle-repair-name/README.md) | Compare names and domain evidence within a clear brief. |
| [L1-05 — Plan community repair sessions](level-1-community-repair/README.md) | Assess a useful noncommercial outcome without inventing revenue. |

### Level 2 — Compare and maintain a case

Resolve economic trade-offs, changed evidence and shared constraints. Preserve earlier decisions.

| Example | What you learn |
| --- | --- |
| [L2-01 — Sell a podcast package or run a service](level-2-podcast-package-or-service/README.md) | Compare asset sale, no sale and retained delivery on the same basis. |
| [L2-02 — Compare children’s audio-story businesses](level-2-childrens-audio/README.md) | Model creative rights, production capacity and different payers. |
| [L2-03 — Compare coffee sampler fulfilment routes](level-2-coffee-sampler-economics/README.md) | Expose the cash gap hidden by a positive per-order margin. |
| [L2-04 — Refresh a case after the specification changes](level-2-changed-software-spec/README.md) | Update the recommendation while preserving the selected route. |
| [L2-05 — Choose the next portfolio investigation](level-2-portfolio-capacity/README.md) | Compare projects without spending the same time or cash twice. |

### Level 3 — Bootstrap a selected project

Turn an accepted route into useful starting assets, exercise them, and prepare a versioned handover.

| Example | What you learn |
| --- | --- |
| [L3-01 — Bootstrap an invoice reconciliation tool](level-3-reconciliation-tool/README.md) | Build and check one local CSV-to-report workflow. |
| [L3-02 — Bootstrap a podcast production service](level-3-podcast-service/README.md) | Create operating assets that can deliver one reviewed sample. |
| [L3-03 — Bootstrap a paid industry briefing](level-3-industry-briefing/README.md) | Produce one sourced issue and test the publication process. |
| [L3-04 — Bootstrap a coffee sampler operation](level-3-coffee-sampler-operation/README.md) | Reconcile an order, stock, costs and a return. |
| [L3-05 — Bootstrap a repair referral service](level-3-repair-referrals/README.md) | Walk a qualified request through matching, fees and dispute handling. |

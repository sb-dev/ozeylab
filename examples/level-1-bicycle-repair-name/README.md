## Exact prompt

```text
Read examples/RUNNING.md and examples/level-1-bicycle-repair-name/brief.md. Follow their evidence, review and execution rules.

Use project-name and domain-check for example-l1-04. Generate distinct naming approaches from the brief and screen the strongest candidates for obvious product, company and brand collisions in the relevant UK sources. Record the scope of each search. Check exact domain candidates only through available authorised live tools. Save provider, time, term, price and renewal evidence. If access is unavailable, keep the status unknown and return a conditional shortlist. Present at most two final names and recommend one. Do not accept a name, register a domain or treat screening as legal clearance.

Report actual output paths, checks performed, unresolved evidence and the next decision. Distinguish a producer self-check from independent review.
```

## Expected outputs

Paths below are relative to `projects/example-l1-04/`.

## Check the result

- No DNS or website result is used to prove registration availability.
- Missing renewal costs remain unknown, and resale is separate from registration.
- The selected name is not changed merely because a candidate looks promising.

Apply the shared verification rules as well. A structural pass does not establish demand, correct judgement or a successful launch.

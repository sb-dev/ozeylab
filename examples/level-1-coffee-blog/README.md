# L1-01 — Explore a coffee blog

[All examples](../README.md) · [Exercise brief](brief.md)

Compare ways to earn from one topic before choosing what to build.

**Status: designed, not executed.** Expected outputs below are acceptance requirements, not recorded results.

## Start

Use the [shared run instructions](../RUNNING.md) in a disposable ozeylab checkout. The brief is supplied input; it is not evidence of demand.

```bash
node scripts/cli.ts create example-l1-01 --spec examples/level-1-coffee-blog/brief.md
```

## Exact prompt

```text
Read examples/RUNNING.md and examples/level-1-coffee-blog/brief.md. Follow their evidence, review and execution rules.

Use case-study-create for example-l1-01. Compare the coffee routes in the brief. Screen all six operating families, then develop only the serious candidates. Identify the reader or customer, payer, useful outcome, acquisition route, delivery work and first possible paid outcome. Challenge the assumed audience and the six-hour capacity. Use current primary sources for changing prices or terms. Keep unmeasured demand and conversion unknown. Recommend one route and one credible alternative, with the next evidence that could change the recommendation. Do not select or launch a route.

Report actual output paths, checks performed, unresolved evidence and the next decision. Distinguish a producer self-check from independent review.
```

## Expected outputs

Paths below are relative to `projects/example-l1-01/`.

- case-study.md: alternatives, baseline and conditional recommendation
- wiki/: source-linked audience, delivery and distribution findings
- finance/: dated models and results for serious alternatives

## Check the result

- A blog, guide and service differ in payer, deliverable and work; marketing channels are not separate operating models.
- The comparison includes unpaid owner time and acquisition effort.
- Zero existing audience does not become invented traffic or revenue.

Apply the shared verification rules as well. A structural pass does not establish demand, correct judgement or a successful launch.

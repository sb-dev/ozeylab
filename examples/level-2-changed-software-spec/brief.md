# Refresh a case after the specification changes — exercise brief

Status: synthetic learning input. No market or execution result is established.

This exercise uses two versions of a fictional invoice-reconciliation requirement. Version 1 proposes uploading CSV files to a hosted service. Version 2 requires local processing and forbids transmitting source rows outside the device. It also reduces owner capacity from eight to four hours per week. No cost or demand claims are measured. Establish and review the version-1 case first in a disposable exercise checkout. Record any exercise-only selection explicitly. The second phase tests whether a new recommendation can coexist with the earlier selected route.

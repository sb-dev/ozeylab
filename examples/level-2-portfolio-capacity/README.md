# L2-05 — Choose the next portfolio investigation

[All examples](../README.md) · [Exercise brief](brief.md)

Compare projects without spending the same time or cash twice.

**Status: designed, not executed.** Expected outputs below are acceptance requirements, not recorded results.

## Start

Complete L1-01, L2-01 and L2-03 first in the same disposable checkout, or use their incomplete state to practise reporting gaps. Read this brief directly. The query does not need a fourth project record.

## Exact prompt

```text
Read examples/RUNNING.md and examples/level-2-portfolio-capacity/brief.md. Follow their evidence, review and execution rules.

Use project-query to compare example-l1-01, example-l2-01 and example-l2-03 under the shared limits in this brief. Read project records, accepted decisions, current cases and the source evidence behind decisive figures. Separate selected commitments from new recommendations. Align decision dates, periods, currency and scenarios where the evidence permits; otherwise show the comparison gap. Identify overlapping weekly work and peak cash demand. Recommend the next investigation and at most one alternative. Do not add mutually exclusive route returns, count speculative exits as cash or modify project records. If an assessment is missing or stale, make that the next evidence need.

Report actual output paths, checks performed, unresolved evidence and the next decision. Distinguish a producer self-check from independent review.
```

## Expected outputs

The output is an answer, not a repository mutation.

- A read-only answer citing project IDs, assessment revisions and decisive source paths
- A comparison of committed work, available capacity and uncertain funding
- One recommended next investigation and the condition that would change it

## Check the result

- Repository content is unchanged by the query.
- Hours and cash limits are shared once across the portfolio.
- Missing or stale data cannot produce a confident total or automatic selection.

Apply the shared verification rules as well. A structural pass does not establish demand, correct judgement or a successful launch.

## Next decision

Authorise the recommended investigation if its remaining cost and evidence need are acceptable.

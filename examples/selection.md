# Example selection

45 candidate exercises were developed: 15 per level. Five per level were selected for the README and expanded into guides. This is an editorial selection, not a market ranking or an executed benchmark.

## Selection criteria

- **Clarity:** a reader can understand the starting problem and next decision.
- **Distinct learning:** the exercise teaches a different repository responsibility.
- **Coverage:** the set spans input forms, operating models and lifecycle work.
- **Checkability:** outputs and failure conditions can be inspected.

Selection balances the set. A deferred candidate can be useful while repeating a lesson already covered. The levels increase responsibility, not document length. Only the selected 15 have full guides.

The assets bootstrap profile remains covered by the L2-01 scope comparison and the existing synthetic package case. This set does not claim to execute every profile. Partner ownership, live registrar access and production integrations need separate exercises.

# Synthetic software bootstrap scope

Example objective: an internal episode-production tracker. This is a noncommercial
scope example, not an accepted project or a completed implementation.

Initial repository: product/development contract, chosen code foundation, setup,
data boundaries, a working create-and-view episode path and checks for that path.
Use docs/launch-spec.md for the first operational outcome and funding/capacity.

Stages: agree behaviour; inspect reusable foundations; implement the starting path;
run setup from a clean checkout; verify an episode can be created and viewed; record
the exact authorised GitHub revision and next unit.

A service bootstrap instead needs intake, quotation, a delivery procedure and an
actual sample through review. Do not substitute a software scaffold for those assets.

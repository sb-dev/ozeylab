# Project knowledge

Read the local ontology and existing claims before incorporating a source.
Initialise the ontology from the material, not a fixed list of business topics.
Write synthesised pages with source IDs, versions and links. Retain disagreements.
Trace additions, contradictions and withdrawals into related pages and finance.

Give the ontology-librarian responsibility for page types, relationships, naming
and navigation. Use a separate read-only reviewer to challenge material updates.
The coordinating agent owns final writes, source states and generated navigation.

Record source version, extraction limits, affectedPages, incorporation and run in
.wiki/source-registry.md. Do not mark ingestion complete merely because a file was copied.
Page-name uniqueness is local to a project. Use explicit paths for cross-project links.

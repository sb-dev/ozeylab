# project-maintain

Use this skill inside an ozeylab checkout. Locate its root through package.json
(name: ozeylab) and AGENTS.md. If absent, request the checkout before proceeding.

Read `processes/project-maintain.md` from that root and execute it.
Read the linked templates and specifications only as the process requires.
Use the repository's tools for source preservation, calculations and validation.
Keep one writer for the project. Record the input revision, process revision,
runner and model settings, output paths, run link and actual checks.

Report what changed, what was verified, what remains unknown and the next action.
